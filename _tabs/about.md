# About Me

I'm **Gustavo**, a cybersecurity professional focused on **Offensive Security** and **Web Application Penetration Testing**.

I created **RedNoctis** as a place to document my practical security studies, penetration testing methodology, CTF solutions, and the reasoning behind each attack path.
